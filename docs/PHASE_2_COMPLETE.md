### Aider CLI Integration

**Command:**
```bash
aider --yes --message "<task>\n\nObservations:\n<obs>\n\nExpert Training:\n<training>" *.go
```

**Flags:**
- `--yes`: Auto-accept all changes (no interactive mode)
- `--message`: Task description + observations + training

**Output:**
- Stdout/stderr captured for logging
- Commit SHA extracted via `git rev-parse HEAD`

## Mental Model Applied

### Cross-Questioning

✅ **Why max 5 iterations?** → Balance between thoroughness and cost  
✅ **Why observe before think?** → Provide context for Aider  
✅ **Why git status?** → Show what files changed  
✅ **Why build/test?** → Verify code works  
✅ **Why Gate 1 only?** → Implementation doesn't need peer review  
✅ **Why per-expert workspaces?** → Prevent git race conditions

### Scenarios Verified

✅ Code works first try → 1 iteration  
✅ Build fails → Aider fixes → 2 iterations  
✅ Tests fail → Aider fixes → 3 iterations  
✅ Max iterations → return partial  
✅ Parallel execution → no git conflicts

### Mental Code Execution

```go
// Workflow: "Build URL Shortener"
// Phase: implementation
// Expert: Backend Engineer
// Task: "Implement URL shortening logic"

runAiderLoop() {
  // Iteration 1
  observations = observeWorkspace()  // Empty
  runAiderIteration(task, observations)
  // Aider creates: shortener.go, shortener_test.go
  // Commit: "feat: add URL shortening logic"
  
  // Iteration 2
  observations = observeWorkspace()
  // Build: FAIL (missing import "crypto/rand")
  runAiderIteration(task, observations)
  // Aider fixes import
  // Commit: "fix: add crypto/rand import"
  
  // Iteration 3
  observations = observeWorkspace()
  // Build: PASS
  // Tests: FAIL (TestShorten: expected 6 chars, got 8)
  runAiderIteration(task, observations)
  // Aider fixes length
  // Commit: "fix: use 6-char short codes"
  
  // Iteration 4
  observations = observeWorkspace()
  // Build: PASS
  // Tests: PASS
  // Task complete! Exit loop
  
  return AiderRunResult{
    CommitSHAs: ["abc123", "def456", "ghi789"],
    Iterations: 4,
    Completed: true,
  }
}
```
